# ジャイロ・ラグナロク（GYRO RAGNAROK）

自分がコマになって戦う 3D バトル。ブラウザで遊べます（PC・スマホ）。

遊ぶ: https://tom3games.github.io/koma-battle/

## 遊び方
- PC: WASD で移動、マウスで狙って左クリックでダッシュ。空中で左クリックすると相手へ急降下。右クリックで必殺技「メテオ・ジャッジメント」
- スマホ: 左側をなぞって移動（触った所が中心）。右側をはじいた向きへダッシュ（空中なら急降下、タップだけなら近くの相手へ）。星のボタンで必殺技
- 回転が体力。0 になるか、縁の切れ目から落ちたら負け
- パーツ（上・芯・足）を 3 種ずつ組み合わせて、能力が変わる
